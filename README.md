# Escala Escolar

Sistema web desenvolvido para facilitar a consulta e o gerenciamento das escalas de funcionários escolares.

O projeto conta com uma interface para que os funcionários consultem suas escalas diárias e semanais, além de uma futura interface administrativa destinada à direção escolar.

**Tecnologias utilizadas:**

* React
* Vite
* Google Apps Script
* Supabase
